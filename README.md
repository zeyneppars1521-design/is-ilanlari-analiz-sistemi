# İş İlanları Analiz Sistemi

## Proje Hakkında
Bu proje, Python kullanılarak iş ilanlarının analiz edilmesi amacıyla geliştirilmiştir.

Proje kapsamında iş ilanları pozisyon, şehir, deneyim seviyesi ve maaş bilgilerine göre incelenmektedir.

## Kullanılan Teknolojiler
- Python
- Pandas
- NumPy
- Matplotlib

## Proje Özellikleri
- İş ilanlarının tabloya aktarılması
- Verilerin filtrelenmesi
- Şehirlere göre ilan sayılarının hesaplanması
- Deneyim seviyelerinin analiz edilmesi
- Maaş istatistiklerinin hesaplanması
- Verilerin grafiklerle görselleştirilmesi
- Excel raporu oluşturulması

## Proje Durumu
Proje geliştirme aşamasındadır.
